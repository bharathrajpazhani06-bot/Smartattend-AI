# 🎓 SmartAttend AI — Student Attendance Tracker & Analytics

An intelligent, zero-backend Single Page Application (SPA) designed to record, monitor, and analyze student attendance with proactive risk classification and an attendance recovery simulator.

---

## 🌟 Key Features

* **⚡ Pure Client-Side SPA**: Zero server dependencies or database latency. Operates entirely via browser `localStorage`.
* **📊 Visual Analytics**: Interactive bar charts powered by **Chart.js** displaying overall and subject-wise attendance percentages.
* **🤖 Smart Attendance Recovery Simulator**: Calculates the exact number of consecutive classes a student must attend to cross the $75\%$ threshold.
* **🛡️ Self-Healing Data Integrity**: Automatically scans and cleans duplicate logs on startup to ensure state consistency.
* **📑 Matrix Report & Excel Export**: Real-time attendance matrix across all subjects with 1-click `.xlsx` file download using **SheetJS**.
* **🌙 Dark / Light Mode**: Dynamic theme toggling styled with Tailwind CSS.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, Vanilla JavaScript (ES6+)
* **Styling**: Tailwind CSS (CDN)
* **Data Visualization**: Chart.js
* **Export Tool**: SheetJS (`xlsx.full.min.js`)
* **Storage**: Browser `localStorage`

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any web browser.
*(No node_modules, npm install, or local server required!)*
